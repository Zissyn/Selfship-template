Mis fichas

    ¿Cómo se usa?
    1. Toca un corazón o la foto para subir tu imagen y arrástrala para acomodarla.
    2. Elige Sharing, Selective o Non-sharing en cada corazón.
    3. Cambia colores y tipografía abajo; usa etiquetas para organizar.
    4. Pulsa «Descargar PNG» para guardar tu ficha.

    Mantén presionada la imagen para guardarla.

    Etiquetas

    Úsalas como carpetas: por fandom, por pareja, por proyecto…

    Ajustar imagen

    Toca una imagen para ajustarla.

    Zoom

    Arrastra la imagen dentro del marco. Con el mouse también puedes usar la rueda.

    Colores

    ¿No sabes qué combinar? Prueba una paleta o «Sorpréndeme»: crea combinaciones armoniosas a partir de un solo tono.

    Exportar

    Tus fichas, imágenes y canciones se quedan en tu dispositivo: no se suben a ningún servidor. Guarda una copia de vez en cuando. Del reproductor se guardan título, portada y corazón; la canción hay que volver a elegirla.
